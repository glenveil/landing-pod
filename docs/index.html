Process

four movements

I

Listen to the room

We observe the process before shaping the why.

II

String the invisible thread

We define what the agent may do, may ask, must cite, and must refuse.

III

Craft the behavior

Prompts, tools, trained memory, retrieval, and interface details are tuned like joinery used in violin making.

IV

Deepens with use

We test with real workflow, refine what matters, and remove noise until the system resonates.

Studio

a small window above an old street, where agent plays a melody

Founded between craft and computation

Agents, crafted like violins.

The studio began inside the Sainte-Geneviève Library, with the realization that shaping knowledge into an AI agent requires a luthier’s careful hand. Time spent learning from Japanese makers revealed that true craft disappears into use. Today, every agent we build carries both traditions: the patience of a French luthier and the restraint of a Japanese maker.

Origin

Sainte-Geneviève Library: 10 Place du Panthéon

Present

Nomadic. We build where the melody leads.

Manifesto

The best AI agents do not shout. They enter quietly, understand the work, guide what matters, and leave the workflow better than they found it.

Less interface, more assistance. Less feature pile. More single-purpose mastery. Less artificial personality. More graceful conduct.
